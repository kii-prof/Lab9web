## Tujuan Praktikum
Mempelajari modularisasi program PHP menggunakan
include, require, template, function, helpers,
struktur direktori, dan routing.

## Kebutuhan Perangkat
- XAMPP
- PHP
- MySQL
- Visual Studio Code
- Browser

## Struktur Project
- latihan/
- aplikasi-crud/
- README.md

## Langkah Praktikum
1. Menguji include dan require.
2. Membuat template header dan footer.
3. Membuat function PHP dan helpers.
4. Menata struktur direktori.
5. Membuat routing dan halaman 404.
6. Mengintegrasikan modularisasi ke aplikasi CRUD
   praktikum sebelumnya.

## Daftar Rute
- index.php
- index.php?page=barang/list
- index.php?page=barang/add
- index.php?page=barang/edit
- index.php?page=barang/delete

## Cara Menjalankan
1. Aktifkan Apache dan MySQL melalui XAMPP.
2. Salin folder Lab9Web ke htdocs.
3. Import database project ke phpMyAdmin.
4. Sesuaikan konfigurasi database.
5. Buka aplikasi melalui localhost.

## Kendala dan Solusi
Kendala:
Localhost tidak dapat diakses karena Apache
belum berjalan.

Solusi:
Mengaktifkan Apache melalui XAMPP Control Panel.

## Kesimpulan
Praktikum ini membantu memahami cara menyusun
aplikasi PHP secara modular agar kode lebih
terstruktur, mudah dikelola, dan dapat digunakan
kembali.
